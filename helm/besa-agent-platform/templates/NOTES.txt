EXTERNAL ACCESS (port {{ .Values.ingress.nodePortHostPort }})

  The webui Service is NodePort {{ .Values.apps.webui.service.nodePort }}. Helm cannot publish a host
  port - k3d must map it once, which recreates the serverlb container (brief
  blip on the Rancher UI and the kubectl API port):

    k3d cluster edit <cluster> --port-add "{{ .Values.ingress.nodePortHostPort }}:{{ .Values.apps.webui.service.nodePort }}@loadbalancer"
    docker port k3d-<cluster>-serverlb

  Then:

    curl.exe -s http://localhost:{{ .Values.ingress.nodePortHostPort }}/healthz
    start http://localhost:{{ .Values.ingress.nodePortHostPort }}
